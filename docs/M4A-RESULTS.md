# M4A 更多归档格式

状态：核心实现、自动测试、Release 构建、本机安装、扩展调用和 Finder 视觉验收全部完成。

## 实现范围

- TAR，以及 GZIP、BZIP2、XZ 压缩的 TAR：`.tar`、`.tar.gz`/`.tgz`、`.tar.bz2`/`.tbz`/`.tbz2`、`.tar.xz`/`.txz`。
- 独立压缩流：`.gz`、`.bz2`、`.xz`，显示单个数据条目；归档库未提供的预先解压尺寸保持未知。
- 完全只读枚举，不把归档内容写入磁盘，不执行归档内文件。
- 显示条目路径、文件夹/文件/链接、已知尺寸、修改时间和压缩方式。
- 最多显示 10,000 项；检测绝对路径、父目录跳转、Windows 盘符等不安全路径。
- 复用 macOS SDK 自带 `libarchive`，不依赖 Homebrew、网络下载或随应用打包的第三方二进制。

## 已知限制

- 只展示目录和元数据，不读取文件正文，也不提供解压操作。
- 独立压缩流通常没有归档目录，系统归档库可能无法在不读取正文的情况下报告解压尺寸。
- 当前未支持 RAR、7Z、LHA、CAB 等格式；是否加入取决于后续依赖、许可证和沙盒验证。
- Finder 实际接管仍需逐种扩展名按空格确认；功能测试通过不代表 Launch Services 已选择 SpaceLens。
