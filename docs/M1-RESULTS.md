# M1 接入原型结果

日期：2026-09-23。环境：Apple Silicon / macOS 27.0 / Xcode 27.0 / Swift 6.4。

## 已实现

- 原生 SwiftUI 宿主；创建验收文件、打开系统设置。
- 原生 QuickLookUI 预览扩展，声明独立验收 UTI 和 public.folder。
- 本地 ad hoc 签名，扩展开启沙盒与用户选择文件只读权限，无网络权限。
- 文件夹浅层枚举与 100 项上限；验收文本 64 KiB 上限；支持取消、读取错误与截断提示。
- 不执行预览内容；不跟随文件夹链接，不读取链接目标内容，拒绝 FIFO 等非普通文件。
- Xcode 工程、Swift Package 核心测试、构建/安装脚本、合成验收样例和 macOS CI 配置。

## 发现并处理的问题

项目位于带文件提供服务的桌面目录，构建产物被附加 FinderInfo，导致签名拒绝。构建及测试脚本已将产物移到本机临时目录，并避免安装时复制额外属性；没有关闭任何系统安全机制。

自动发送 Finder 空格键受到辅助功能权限限制。没有变更系统权限，使用用户实际按键确认并与自身扩展日志交叉验证。

## 范围限制

这是接入原型。文件夹尚无递归树、大小统计或搜索；不支持 ZIP 等后续格式。列表达到上限时只对已读取的条目排序，不保证截断结果是全目录排序的前 100 项。macOS 12 只是当前部署目标，不代表兼容性已经实测。没有做 Apple 公证，不承诺下载到其他 Mac 后直接运行。

后续 M2 在当前已验证的接入方式上实现完整文件夹呈现与 ZIP；先保留明确的读取预算和异常提示。
