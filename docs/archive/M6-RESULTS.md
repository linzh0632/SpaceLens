# M6 文件修改时间列

## 本阶段范围

M6 为文件夹、ZIP 和其他归档的树形列表增加“修改时间”列。时间直接使用文件系统或归档条目中的元数据；缺少时间的条目显示“—”。JSON、plist、SQLite 等结构化预览继续使用原有三列布局。
