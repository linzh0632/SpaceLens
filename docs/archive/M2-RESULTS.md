# M2 文件夹与 ZIP

状态：实现、自动测试、Release 构建和本机安装完成；树状界面已在 Quick Look 中实机显示。

## 实现范围

- 文件夹递归树：最多 10,000 项、10 层，显示文件/文件夹/包/符号链接、文件大小和修改时间。
- 不跟随符号链接，不进入 macOS 包目录；达到条目或深度上限时明确标记截断。
- ZIP 只读取结束记录和中央目录，不解压文件内容。
- ZIP 显示路径、压缩前后大小、压缩方法和修改时间。
- 加密条目、不安全路径和异常压缩比均显示警告；损坏、分卷 ZIP 和 ZIP64 返回明确说明。
- ZIP 列表最多 10,000 项，解析支持任务取消。
- 文件夹和 ZIP 使用原生树状表格，支持展开/折叠，并显示文件图标、名称、类型和大小列。

## 安全边界

SpaceLens 不创建归档内文件，不使用归档路径写磁盘，因此不会触发路径穿越解压。压缩炸弹检测基于中央目录元数据，仅作为预览警告；它不替代解压工具自身的安全限制。文件名优先按 UTF-8 解码，旧式非 UTF-8 ZIP 的字符集显示可能不准确。

## 已知限制

- M2 不支持 ZIP64、分卷 ZIP、TAR、GZ、TGZ、TBZ2 或 TXZ。
- ZIP 只展示元数据，不打开归档内文件。
- 文件夹大小是已扫描普通文件大小之和；包目录和被截断部分不计入。
- Quick Look 扩展一次只接收当前项目，无法直接读取 Finder 的“最近文件”列表；如需类似侧栏，需要由 SpaceLens 主应用自行记录历史。
