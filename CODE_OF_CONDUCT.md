# Code of Conduct / 行为准则

SpaceLens welcomes people of every background and experience level. Participation in Issues, Pull Requests, reviews, and other project spaces should remain respectful, constructive, and focused on improving the project.

Examples of positive participation include giving specific technical feedback, respecting different viewpoints, accepting corrections, and protecting other people's privacy. Harassment, personal attacks, discriminatory language, deliberate disruption, and publishing another person's private information are not acceptable.

Project maintainers may edit or remove contributions that violate these expectations and may temporarily or permanently restrict participation when necessary.

To report a conduct concern, follow the private-contact guidance in [SECURITY.md](SECURITY.md). Do not publish sensitive details in a public Issue. Reports will be handled as privately and promptly as the available GitHub communication tools allow.

---

SpaceLens 欢迎不同背景和经验水平的参与者。在 Issue、Pull Request、代码审查及其他项目交流中，请保持尊重、友善和建设性，并围绕项目改进展开讨论。

积极参与包括提供具体的技术反馈、尊重不同观点、接受合理纠正，以及保护他人的隐私。骚扰、人身攻击、歧视性言论、蓄意扰乱讨论，以及公开他人隐私信息等行为不可接受。

项目维护者可以编辑或移除违反这些要求的内容，并在必要时暂时或永久限制相关参与者继续参与。

如需报告行为问题，请按照 [SECURITY.md](SECURITY.md) 中的私下联系指引处理，不要在公开 Issue 中披露敏感细节。维护者会在 GitHub 现有沟通方式允许的范围内，尽快并尽量私密地处理报告。
