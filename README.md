# SpaceLens · 空格镜

按下空格，多看一点。

面向 macOS 的本地快速预览增强工具，保留系统原生预览体验，并以 Super Quick Look 的公开功能为首版对照目标。

**当前状态：开发准备阶段，暂无可运行应用。**

计划支持文件夹、归档、文档与图表、源代码与配置、表格数据与数据库预览。详情见 [开发准备](SpaceLens-PREPARATION.md)。

## 开发环境

- 完整 Xcode 与匹配的 macOS SDK（待安装并验证）
- Swift、Git
- macOS 12 为候选最低版本，最终以兼容性验证为准
